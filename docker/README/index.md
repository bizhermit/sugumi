# 本番環境

本番環境の構築・運用手順。
ビルドサーバーでイメージをビルドしてレジストリに登録し、ロードバランサー・アプリサーバー（1 台以上）・DB サーバーで取得して起動する。
サーバー構成は「[本番環境の構築方法](setup.md#サーバー構成)」、構成図はリポジトリの [README.md](../../README.md#本番) を参照。

## 対象者と前提知識

本番環境を構築・運用する人。次の知識を前提とする。

- Linux のシェル
- Docker Compose
- nginx
- PostgreSQL の `psql`
- ログを CloudWatch Logs に送る場合は、AWS の IAM・EC2・CloudWatch Logs
