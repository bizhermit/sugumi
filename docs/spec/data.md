## 2. テーブル定義

（現時点で0件。テーブルが追加された時点で、テーブルごとに `### <テーブル名>` の節を追加する。）

### 2.0 節とカラム表の書式規約（機械検査が前提とする形）

- テーブルごとに **`### <テーブル名>` の節**を持ち、その中にカラム表を1つ置く（規約 §11.8）。
- カラム表の列は次の**7列・この順で固定**する。

  `| 列 | 型 | NOT NULL | 既定値 | PK | 意味 | 個人情報 |`

  - 先頭5列（`列` / `型` / `NOT NULL` / `既定値` / `PK`）は `PRAGMA table_info` の
    `name` / `type` / `notnull` / `dflt_value` / `pk` に対応し、**列順も `cid` 順**とする
    （規約 §11.8 / §12.4-47）。既定値が無い場合は `—`（全角ダッシュ）を書く。
  - `意味`（日本語1行）と `個人情報`（`あり` / `なし` / `ハッシュ`）は人手で書く。
- **空欄を作らず `—` を書く**（規約 §11.8）。
- インデックスを張る場合は同じテーブル節内に別表で示し、「なぜ張ったか」を人手で書く
  （規約 §12.4-48）。
